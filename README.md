# MegaClean Homepage Demo

Responsive multi-page site inspired by the provided MegaClean homepage reference. Pages: `index.html`, `services.html`, `locations.html`, and `about.html`.

## Publish with GitHub Pages

1. Add the files in this folder to the root of a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the default branch and `/ (root)`, then save.

The homepage hero uses the owner portrait supplied by the user at `assets/owner-hero.png`. CSS adds a framed layout and lightweight motion while leaving the portrait itself unchanged. Motion is disabled when the visitor has requested reduced motion.

Navigation dropdowns open on hover and keyboard focus on desktop, and via tap on mobile. The quote form prepares an email draft for `info@megaclean.com`; it does not submit automatically. Other photos and fonts load from external services.

The service area and contact details follow the supplied reference: Tulsa, Owasso, Bixby, Broken Arrow, Jenks; +1 918 217 6468. Before-and-after gallery photos are illustrative stock images. Replace them with MegaClean's own verified project photos before presenting them as actual customer results.
